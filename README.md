
# MaCroS
MaCroS is a completely free messenger, aimed first and foremost at Russian citizens without confidential messenger alternatives

With Telegram's blockage it is as important as ever to be able to keep in touch with your relatives, family and friends. MaCroS will help with that!
I would be more than happy to gather a team, so if you're interested in joining this project's future you can contact me by emailing kittyheart4ever@gmail.com; I will be pleased to answer anything you ask me! 


This project is written fully in Python 3.12, with PyCharm as interpreter. No AI was involved.
